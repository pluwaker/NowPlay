# Изменение порта по умолчанию: 8080 → 58080

## Причина изменения

Порт 8080 часто используется различными приложениями:
- Альтернативный HTTP порт
- Прокси-серверы
- Серверы разработки (Tomcat, Jenkins, и др.)
- Различные веб-приложения

Это приводило к конфликтам и необходимости вручную искать свободный порт.

## Новый порт: 58080

**Преимущества:**
- ✅ Находится в диапазоне динамических портов (49152-65535)
- ✅ Редко используется стандартными приложениями
- ✅ Легко запомнить (58080 = 5 + 8080)
- ✅ Минимальный риск конфликтов

**Диапазон поиска:** 58080-59000 (920 портов)

## Миграция

### Для пользователей

**Ничего делать не нужно!** Приложение автоматически будет использовать новый порт.

При запуске вы увидите:
```
✅ Сервер запущен на http://localhost:58080
✅ MediaMonitor started (PID: 12345, Port: 58080)
```

### Для разработчиков

1. **Пересоберите MediaMonitor.exe:**
   ```bash
   cd MediaMonitor
   dotnet build -c Release
   ```

2. **Обновите закладки/ссылки:**
   - Старый URL: `http://localhost:8080`
   - Новый URL: `http://localhost:58080`

3. **Обновите конфигурации OBS:**
   - Измените URL источника Browser Source на новый порт

## Обратная совместимость

✅ Можно вручную указать любой порт:
