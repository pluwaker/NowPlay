## Краткое описание проекта

**Цель:** Разработка кроссплатформенной системы управления и визуализации мультимедийного контента для стриминговых сервисов с поддержкой автоматического отображения информации о текущем воспроизводимом контенте, настройки визуализации и автоматического извлечения цветовой палитры из обложек.

**Основные задачи:**
1. Разработать трёхуровневую архитектуру системы (Desktop App + Web Server + Frontend Widgets)
2. Реализовать интеграцию с системными API медиаплееров для получения информации о контенте (Windows Media Control API, с возможностью расширения на другие платформы)
3. Создать систему получения метаданных контента (обложек, информации о треках) из различных источников (Last.fm, iTunes, Yandex Music, VK Music)
4. Разработать 4 веб-виджета с настраиваемыми шаблонами визуализации мультимедийного контента
5. Реализовать алгоритм автоматического извлечения цветовой палитры из обложек для адаптации интерфейса
6. Оптимизировать производительность системы (снижение нагрузки CPU с 20-35% до 0.8-2%)
7. Обеспечить интеграцию с популярными стриминговыми сервисами (OBS Studio, Streamlabs и др.)

**Технологии:** Python 3.12+, CustomTkinter, aiohttp, WebSocket, Windows Media Control API (с возможностью расширения), HTML/CSS/JavaScript, PyInstaller

**Результат:** Кроссплатформенная система управления и визуализации мультимедийного контента с установщиком, интегрирующаяся со стриминговыми сервисами через Browser Source, с оптимизированной производительностью и автоматическим извлечением цветов из обложек. Система обеспечивает единообразный интерфейс для управления и визуализации мультимедийного контента в различных стриминговых приложениях.
