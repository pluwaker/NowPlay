## 📊 КЛЮЧЕВЫЕ ДАННЫЕ ПРОЕКТА

### Название
**NowPlay** - Система управления и визуализации мультимедийного контента для стриминговых сервисов

### Технологии
- Python 3.12+, CustomTkinter, aiohttp
- Windows Media Control API
- WebSocket, HTML/CSS/JavaScript
- C# .NET 6.0 (опционально)

### Архитектура
- **Уровень 1:** Desktop Application (GUI)
- **Уровень 2:** Web Server (API + WebSocket)
- **Уровень 3:** Frontend Widgets (HTML/CSS/JS)

### Результаты оптимизации
- **CPU:** 20-35% → 0.8-2% (снижение в 10-20 раз)
- **Время обработки:** 150ms → 20ms (ускорение в 7.5 раз)
- **Память:** < 200 МБ (стабильно)
- **Стабильность:** 48+ часов непрерывной работы

### Системные требования
**Минимальные:**
- Windows 10 (64-bit)
- Intel Core i3 / AMD Ryzen 3
- 4 ГБ RAM
- 500 МБ диск

**Рекомендуемые:**
- Windows 11
- Intel Core i5 / AMD Ryzen 5
- 8 ГБ RAM
- 1 ГБ диск

## 🔄 КЛЮЧЕВЫЕ АЛГОРИТМЫ

### Алгоритм извлечения цветов
1. Загрузка изображения в canvas (80x80px)
2. Получение данных пикселей
3. Выборка с шагом 128 байт
4. Группировка похожих цветов
5. Фильтрация серых/темных
6. Выбор контрастных цветов
7. Кэширование результата

### Алгоритм получения обложек
1. Приоритизация источников (Last.fm → iTunes → Yandex → VK)
2. Попытка получения от каждого
3. Обработка ошибок (timeout, 404)
4. Fallback на дефолтную обложку
5. Кэширование результата

### Алгоритм мониторинга медиа
1. Опрос API каждую секунду
2. Сравнение artist/title
3. Параллельная загрузка обложки и длительности
4. Отправка на Python сервер
5. Рассылка по WebSocket
