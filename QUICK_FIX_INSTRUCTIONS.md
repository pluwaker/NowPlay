# Быстрое исправление проблемы с портом

## Что было исправлено

MediaMonitor был настроен на порт **8080**, а должен был использовать **58080**.

## Изменения

1. ✅ **MediaMonitor/MediaMonitor.cs** - порт изменен с 8080 на 58080
2. ✅ **ui/app.py** - диапазон поиска портов изменен с 8080-9000 на 58080-59000
3. ✅ **MediaMonitor пересобран** - новая версия готова к использованию

## Как запустить

### Вариант 1: Через UI приложение (рекомендуется)

```bash
python main.py
```

1. Нажмите кнопку "🚀 START"
2. Сервер запустится на порту 58080
3. MediaMonitor автоматически подключится к серверу
4. Откройте виджет по ссылке из интерфейса

### Вариант 2: Вручную

1. **Запустите Python сервер:**
   ```bash
   python -c "from now_server.now import run_server; run_server(port=58080)"
   ```

2. **Запустите MediaMonitor:**
   ```bash
   cd MediaMonitor
   .\bin\Release\net6.0-windows10.0.19041.0\MediaMonitor.exe
   ```

3. **Откройте виджет:**
   ```
   http://localhost:58080/index.html
   ```

## Проверка работы

### 1. Проверьте, что сервер запущен

Откройте в браузере: `http://localhost:58080/`

Вы должны увидеть интерфейс выбора виджета.

### 2. Проверьте, что MediaMonitor отправляет данные

В консоли MediaMonitor должны быть сообщения:
```
✅ MediaMonitor запущен!
🔗 Подключение к серверу: http://localhost:58080
✅ Update sent to Python server
```

### 3. Проверьте, что виджет получает данные

Откройте любой виджет (например, `visualisation_var3_horizontal.html`).
Вы должны увидеть информацию о текущем треке.

## Устранение проблем

### Проблема: "Порт 58080 занят"

**Решение:** Закройте другие приложения, использующие этот порт, или приложение автоматически найдет свободный порт в диапазоне 58080-59000.

### Проблема: MediaMonitor не отправляет данные

**Решение:**
1. Убедитесь, что Python сервер запущен ПЕРВЫМ
2. Перезапустите MediaMonitor
3. Проверьте, что в MediaMonitor.cs указан правильный порт (58080)
4. Запустите MediaMonitor с флагом `--diagnostic` для подробных логов:
   ```bash
   MediaMonitor.exe --diagnostic
   ```

### Проблема: Виджеты не загружаются

**Решение:**
1. Проверьте, что сервер запущен: `http://localhost:58080/`
2. Проверьте консоль браузера (F12) на наличие ошибок
3. Убедитесь, что файлы виджетов находятся в папке `now_server/`
