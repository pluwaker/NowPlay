# ТРЕБОВАНИЯ ГОСТ К ТЕХНИЧЕСКОМУ ЗАДАНИЮ

## ГОСТ 19.201-78 "Техническое задание. Требования к содержанию и оформлению"

### Основные положения

Технические задания должны содержать следующие разделы:

1. **Введение**
2. **Основания для разработки**
3. **Назначение разработки**
4. **Требования к программе или программному изделию**
5. **Требования к программной документации**
6. **Технико-экономические показатели**
7. **Стадии и этапы разработки**
8. **Порядок контроля и приемки**
9. **Приложения**

## ГОСТ 34.602-89 "Техническое задание на создание автоматизированной системы"

### Структура технического задания

#### 1. Общие сведения
- Полное наименование системы и ее условное обозначение
- Шифр темы или шифр (номер) договора
- Наименование предприятий (объединений) разработчика и заказчика (пользователя) системы
- Перечень документов, на основании которых создается система
- Плановые сроки начала и окончания работы по созданию системы

#### 2. Назначение и цели создания (развития) системы
- Назначение системы
- Цели создания системы

#### 3. Характеристика объектов автоматизации
- Краткие сведения об объекте автоматизации
- Сведения об условиях эксплуатации объекта автоматизации

#### 4. Требования к системе
- Требования к системе в целом
- Требования к функциям (задачам), выполняемым системой
- Требования к видам обеспечения

#### 5. Состав и содержание работ по созданию системы
- Перечень стадий и этапов работ
- Сроки выполнения работ

#### 6. Порядок контроля и приемки системы
- Виды, состав, объем и методы испытаний системы
- Общие требования к приемке работ по стадиям
- Статус приемки системы

## ГОСТ 7.0.5-2008 "Библиографическая ссылка"

### Требования к оформлению списка литературы

#### Книги
Фамилия, И.О. Название книги / И.О. Фамилия. – Место издания : Издательство, Год. – Количество страниц.

**Пример:**
Таненбаум, Э. Современные операционные системы / Э. Таненбаум. – СПб. : Питер, 2015. – 1120 с.

#### Статьи из журналов
Фамилия, И.О. Название статьи / И.О. Фамилия // Название журнала. – Год. – № номер. – С. страницы.

**Пример:**
Иванов, И.И. Методы оптимизации веб-приложений / И.И. Иванов // Программирование. – 2020. – № 3. – С. 45-52.

#### Электронные ресурсы
Название ресурса [Электронный ресурс]. – Режим доступа: URL (дата обращения: дд.мм.гггг).

**Пример:**
Python Documentation [Электронный ресурс]. – Режим доступа: https://docs.python.org/ (дата обращения: 01.12.2024).

## Требования к оформлению документа

### Шрифт и интервалы
- **Шрифт:** Times New Roman, 14 пт
- **Межстрочный интервал:** 1,5
- **Выравнивание:** По ширине
- **Абзацный отступ:** 1,25 см

### Поля страницы
- **Левое:** 30 мм
- **Правое:** 10 мм
- **Верхнее:** 20 мм
- **Нижнее:** 20 мм

### Нумерация
- **Страницы:** Арабскими цифрами в правом верхнем углу
- **Разделы:** 1, 2, 3...
- **Подразделы:** 1.1, 1.2, 2.1...
- **Пункты:** 1.1.1, 1.1.2...

### Заголовки
- **Разделы:** ПРОПИСНЫМИ БУКВАМИ, полужирный, по центру
- **Подразделы:** Строчными буквами (первая прописная), полужирный, по левому краю
- **Отступ после заголовка:** 1 пустая строка

### Рисунки и таблицы
- **Рисунки:** Подпись снизу: "Рисунок 1 – Название"
- **Таблицы:** Подпись сверху: "Таблица 1 – Название"
- **Нумерация:** Сквозная по всему документу или в пределах раздела

### Список литературы
- Минимум 20 источников для ВКР
- Оформление по ГОСТ 7.0.5-2008
- Нумерация в порядке упоминания или по алфавиту

## Специфические требования для ВКР

### Объем работы
- **Пояснительная записка:** 60-80 страниц
- **Введение:** 2-3 страницы
- **Основная часть:** 50-70 страниц
- **Заключение:** 2-3 страницы
- **Список литературы:** 2-4 страницы

### Структура ВКР
1. Титульный лист
2. Задание на ВКР
3. Реферат (аннотация)
4. Содержание (оглавление)
5. Введение
6. Основная часть (3-4 главы)
7. Заключение
8. Список литературы
9. Приложения

### Содержание введения
- Актуальность темы
- Цель работы
- Задачи работы (5-7 задач)
- Объект исследования
- Предмет исследования
- Методы исследования
- Практическая значимость

### Содержание заключения
- Краткое изложение результатов по каждой задаче
- Выводы (соответствуют задачам)
- Практическая значимость результатов
- Перспективы развития
