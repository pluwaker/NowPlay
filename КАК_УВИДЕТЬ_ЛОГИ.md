# 🔍 Как увидеть логи MediaMonitor

## Проблема

Когда MediaMonitor запускается через UI приложение (`python main.py`), консоль не видна, и логи не отображаются.

## Решение 1: Запустить MediaMonitor с консолью (РЕКОМЕНДУЕТСЯ)

### Вариант A: Через bat-файл

Просто запустите:
```
start_mediamonitor_with_console.bat
```

Откроется консоль с логами MediaMonitor.

### Вариант B: Вручную

```bash
cd MediaMonitor\bin\Release\net6.0-windows10.0.19041.0
MediaMonitor.exe
```

Консоль останется открытой, и вы увидите все логи.

## Решение 2: Использовать диагностический режим с файлом логов

### Шаг 1: Запустите с флагом --diagnostic

```bash
cd MediaMonitor\bin\Release\net6.0-windows10.0.19041.0
MediaMonitor.exe --diagnostic
```

### Шаг 2: Откройте файл лога

Логи сохраняются в:
```
MediaMonitor\logs\mediamonitor_YYYYMMDD_HHMMSS.log
```

Например:
```
MediaMonitor\logs\mediamonitor_20241208_193045.log
```

### Шаг 3: Просмотрите лог

```bash
type MediaMonitor\logs\mediamonitor_20241208_193045.log
```

Или откройте файл в любом текстовом редакторе.

## Решение 3: Запустить Python сервер и MediaMonitor отдельно

### Шаг 1: Запустите Python сервер

```bash
python -c "from now_server.now import run_server; run_server(port=58080)"
```

### Шаг 2: В ДРУГОМ окне запустите MediaMonitor

```bash
cd MediaMonitor\bin\Release\net6.0-windows10.0.19041.0
MediaMonitor.exe
```

Теперь вы видите логи обоих компонентов в отдельных окнах.

## Быстрый тест

### 1. Остановите UI приложение

Если запущено `python main.py` - закройте его.

### 2. Запустите bat-файл

```
start_mediamonitor_with_console.bat
```

### 3. Включите музыку

Включите любой медиа-плеер (Spotify, iTunes и т.д.)

### 4. Наблюдайте за консолью

Вы должны увидеть:
- Сообщения о запуске
- Heartbeat проверки каждые 5 секунд
- Восстановление через 30 секунд (если события не срабатывают)

### 5. Смените трек

Смените трек в медиа-плеере и проверьте, появляются ли сообщения:

```
🎵 Event: MediaPropertiesChanged at 19:30:45.123
  - Artist - Title
✅ Update sent to Python server
```

## Проблемы и решения

### Проблема: "MediaMonitor.exe не найден"

**Решение:** Пересоберите MediaMonitor:
```bash
cd MediaMonitor
dotnet build -c Release
```

### Проблема: "Порт 58080 занят"

**Решение:** Убедитесь, что Python сервер НЕ запущен, или запустите его отдельно.

### Проблема: "Консоль сразу закрывается"

**Решение:** Используйте bat-файл `start_mediamonitor_with_console.bat` - он добавляет `pause` в конце.
