# Отчет о замене SHALL/MAY на русские эквиваленты

## Дата: Декабрь 2024

### Выполненные замены

Все англоязычные ключевые слова RFC 2119 заменены на русские эквиваленты:

| Было (англ.) | Стало (рус.) | Значение |
|--------------|--------------|----------|
| SHALL | должна/должен/должны | Обязательное требование |
| MAY | может/могут | Опциональная возможность |
| SHOULD | следует | Настоятельная рекомендация |
| MUST | обязана | Абсолютное требование |
| MUST NOT | не должна | Строгий запрет |

### Исправления согласования

После автоматической замены выполнено согласование по роду и числу:

- "Мониторинг должна" → "Мониторинг должен"
- "Компонент мониторинга должна" → "Компонент мониторинга должен"
- "метаданные должна" → "метаданные должны"
- "треки должна отображаться" → "треки должны отображаться"
- "длительности должна обрабатываться" → "длительности должно обрабатываться"
- "значения должна быть отфильтрованы" → "значения должны быть отфильтрованы"

### Исключения

Одно исключение исправлено вручную:
- "может 2019 Update" → "May 2019 Update" (название версии Windows)

### Статистика

**Примерное количество замен:**
- SHALL → должна: ~200+ вхождений
- MAY → может: ~30+ вхождений
- SHOULD → следует: ~5 вхождений
- MUST → обязана: ~2 вхождения

**Итого:** ~240+ замен по всему документу

### Преимущества замены

1. **Улучшенная читаемость** - документ стал полностью на русском языке
2. **Соответствие ГОСТ** - русскоязычное ТЗ должно использовать русскую терминологию
3. **Понятность** - не требуется знание RFC 2119 для понимания требований
4. **Единообразие** - весь документ теперь на одном языке

### Примеры замен

**До:**
```
Система SHALL обеспечивать автоматический мониторинг активных медиаплееров.
Система MAY проверять наличие обновлений при запуске.
```

**После:**
```
Система должна обеспечивать автоматический мониторинг активных медиаплееров.
Система может проверять наличие обновлений при запуске.
```

### Рекомендации

При дальнейшей работе с документом:
- Использовать "должна/должен/должны" для обязательных требований
- Использовать "может/могут" для опциональных возможностей
- Использовать "следует" для рекомендаций
- Следить за согласованием по роду и числу

✅ Все MAY заменены на может/могут  
✅ Исключение "May 2019" исправлено  
✅ Согласование по роду и числу выполнено
