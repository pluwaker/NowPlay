# Диагностика цепочки событий

## Проблема
MediaMonitor получает события (TimelinePropertiesChanged, PlaybackInfoChanged), но обновления не доходят до виджета.

## Добавлено расширенное логирование

Теперь в коде добавлены логи на каждом этапе передачи данных:

### 1. EventSubscriptionManager.OnMediaUpdated()
```
🔔 OnMediaUpdated вызван: {Artist} - {Title}, Position: {Position}s, IsPlaying: {IsPlaying}
   Подписчиков на MediaUpdated: {count}
   MediaUpdated.Invoke завершен
```

### 2. MediaMonitor.OnMediaUpdated()
```
📥 MediaMonitor.OnMediaUpdated получил событие: {Artist} - {Title}
   State обновлен: Position={Position}s, IsPlaying={IsPlaying}
   Вызываем updateQueue.QueueUpdate...
   updateQueue.QueueUpdate завершен
```

### 3. UpdateQueue.ProcessUpdate()
```
🔄 UpdateQueue: Attempting to acquire update lock (timeout: 5s)
✅ UpdateQueue: Lock acquired in {time}ms
📤 UpdateQueue: Processing update for {Artist} - {Title}
✅ UpdateQueue: Update processed successfully
🔓 UpdateQueue: Lock released
```

### 4. MediaMonitor.OnUpdateReady()
```
📤 MediaMonitor.OnUpdateReady вызван для: {Artist} - {Title}
   Отправляем данные на http://localhost:58080/update_from_cs
   Position: {Position}s, IsPlaying: {IsPlaying}
✅ Update sent to Python server
```

## Как проверить

1. Запустите MediaMonitor через bat файл:
   ```
   start_mediamonitor_with_console.bat
   ```

2. Переключите трек или перемотайте позицию в плеере

3. Смотрите на логи в консоли MediaMonitor

4. Проверьте, какие из этих сообщений появляются, а какие нет

## Возможные проблемы

### Если видите только "Event: TimelinePropertiesChanged" но НЕ видите "🔔 OnMediaUpdated вызван"
**Проблема:** OnMediaUpdated() не вызывается из обработчиков событий
**Решение:** Проверить, что в OnTimelinePropertiesChanged и OnPlaybackInfoChanged есть вызов OnMediaUpdated()

### Если видите "🔔 OnMediaUpdated вызван" но "Подписчиков на MediaUpdated: 0"
**Проблема:** MediaMonitor не подписан на событие MediaUpdated
**Решение:** Проверить, что в MediaMonitor.Start() есть строка:
```csharp
eventSubscriptionManager.MediaUpdated += OnMediaUpdated;
```

### Если видите "🔔 OnMediaUpdated вызван" но НЕ видите "📥 MediaMonitor.OnMediaUpdated получил событие"
**Проблема:** Событие не доходит до MediaMonitor.OnMediaUpdated
**Решение:** Проверить подписку на событие

### Если видите "📥 MediaMonitor.OnMediaUpdated получил событие" но НЕ видите "🔄 UpdateQueue: Attempting to acquire update lock"
**Проблема:** updateQueue?.QueueUpdate() не вызывается или updateQueue == null
**Решение:** Проверить инициализацию updateQueue в MediaMonitor.Start()

### Если видите "🔄 UpdateQueue: Attempting to acquire update lock" но НЕ видите "✅ UpdateQueue: Lock acquired"
**Проблема:** Блокировка не может быть получена (deadlock или timeout)
**Решение:** Проверить, нет ли других процессов, удерживающих блокировку

### Если видите "📤 UpdateQueue: Processing update" но НЕ видите "📤 MediaMonitor.OnUpdateReady вызван"
**Проблема:** Событие UpdateReady не подписано
**Решение:** Проверить, что в MediaMonitor.Start() есть строка:
```csharp
updateQueue.UpdateReady += OnUpdateReady;
```

### Если видите "📤 MediaMonitor.OnUpdateReady вызван" но НЕ видите "✅ Update sent to Python server"
**Проблема:** HTTP запрос не отправляется или падает с ошибкой
**Решение:** Проверить логи HttpClientPool и убедиться, что Python сервер запущен на порту 58080
