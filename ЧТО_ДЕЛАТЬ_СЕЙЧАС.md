## 📋 Пошаговая инструкция

### Шаг 1: Запустите MediaMonitor с диагностикой (если еще не запущен)

```bash
cd MediaMonitor\bin\Release\net6.0-windows10.0.19041.0
.\MediaMonitor.exe --diagnostic
```

### Шаг 2: Проверьте, что HealthMonitor запустился

В консоли должно быть:
```
✅ HealthMonitor started (timeout: 30s, heartbeat: 5s)
```

**Если этой строки НЕТ** - сообщите мне, это проблема!

### Шаг 3: Подождите 30 секунд

Просто ждите. Не трогайте ничего.

### Шаг 4: Проверьте, что восстановление сработало

Должны появиться сообщения о восстановлении (см. выше).

### Шаг 5: Смените трек

После восстановления смените трек в медиа-плеере.

Должно появиться:
```
🎵 Event: MediaPropertiesChanged at 19:30:45.123
  - New Artist - New Title
✅ Update sent to Python server
```

### Шаг 6: Проверьте виджет

1. Откройте виджет в браузере
2. Нажмите **F5** (обновить страницу)
3. Проверьте, отображается ли обложка

## 🔍 Проверка обложки

### Проверка 1: Файл существует?

```bash
dir songinfo\cover.png
```

Должен показать файл.

### Проверка 2: Сервер отдает обложку?

Откройте в браузере:
```
http://localhost:58080/cover
```

Должна открыться обложка.

### Проверка 3: Виджет получает обложку?

1. Откройте виджет
2. Нажмите F12 (консоль браузера)
3. Перейдите на вкладку Network
4. Обновите страницу (F5)
5. Найдите запрос к `/cover`
6. Проверьте статус (должен быть 200 OK)

## ❌ Если восстановление НЕ сработало через 30 секунд

**Ищите строку:**

**Если её НЕТ:**
- HealthMonitor не запустился
- Это баг в коде
