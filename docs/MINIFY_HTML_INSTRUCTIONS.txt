===============================================
ИНСТРУКЦИЯ: Минификация HTML файлов
===============================================

Запуск скрипта минификации:

1. Откройте командную строку (cmd) или PowerShell
2. Перейдите в папку проекта:
   cd "H:\ВКР\NowPlay"
   
3. Запустите скрипт:
   python minify_html.py

Или используйте полный путь:
   python "H:\ВКР\NowPlay\minify_html.py"

===============================================

Что делает скрипт:
- Удаляет лишние пробелы и переносы строк
- Удаляет HTML комментарии
- Минифицирует CSS внутри <style>
- Минифицирует JavaScript внутри <script>

Ожидаемая экономия: ~30-40% размера файлов

===============================================

ВАЖНО: Скрипт перезаписывает исходные файлы!
Сделайте backup перед запуском!

Для отката используйте git:
   git checkout now_server/*.html
