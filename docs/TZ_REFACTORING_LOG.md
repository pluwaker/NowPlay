### Принципы работы с перечислениями

**Когда УБИРАТЬ списки:**
- Простое перечисление без иерархии
- Описательная информация
- Последовательность действий, которую можно описать текстом
- Характеристики, которые естественно читаются в предложении

**Когда ОСТАВЛЯТЬ списки:**
- Технические спецификации (endpoints, параметры)
- Нормативные требования (SHALL, MUST, MAY)
- Иерархические структуры с важным порядком
- Справочная информация для быстрого поиска
- Чек-листы и критерии проверки

### Метрики

**До рефакторинга:**
- Примерное количество маркированных списков: ~150-200
- Средняя длина списка: 4-6 пунктов

**После рефакторинга (текущее состояние):**
- Удалено списков: ~15-20
- Преобразовано пунктов в текст: ~80-100

**Целевые показатели:**
- Сократить количество списков на 40-50%
- Оставить только структурно необходимые перечисления
