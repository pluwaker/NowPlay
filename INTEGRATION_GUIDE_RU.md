# 🎵 Руководство по интеграции MediaMonitor

## Что было сделано

Создана интеграция между C# приложением **MediaMonitor** и Python сервером **now.py**:

- ✅ C# приложение отслеживает текущий трек в Windows Media
- ✅ Автоматически загружает и сохраняет обложки альбомов
- ✅ Отправляет данные (исполнитель, название, позицию, длительность) на Python сервер
- ✅ Python сервер рассылает обновления всем подключенным клиентам через WebSocket

## Быстрый старт

### Вариант 1: Автоматический запуск (рекомендуется)

Просто запустите файл:
```
start_media_monitor.bat
```

Это запустит оба компонента автоматически.

### Вариант 2: Ручной запуск

**Шаг 1:** Запустите Python сервер
```bash
python main.py
```

**Шаг 2:** Запустите C# MediaMonitor
```bash
cd MediaMonitor
dotnet run
```

## Как это работает

```
Windows Media → C# MediaMonitor → HTTP POST → Python Server → WebSocket → Браузер/OBS
```

1. **C# MediaMonitor** подключается к Windows Media Control API
2. При смене трека:
   - Получает название и исполнителя
   - Загружает обложку в `songinfo/cover.png`
   - Отправляет данные на Python сервер через HTTP POST
3. **Python сервер** получает данные и рассылает их всем подключенным клиентам
4. **Веб-интерфейс** обновляется в реальном времени

## Настройка

### Отключение встроенного Python мониторинга

Если вы используете C# MediaMonitor, рекомендуется отключить встроенный Python мониторинг для избежания конфликтов.

Добавьте в конфигурацию:
```json
{
  "use_builtin_monitor": false
}
```

### Изменение порта сервера

**В `now_server/now.py`:**
```python
def run_server(port=80):
```

**В `MediaMonitor/MediaMonitor.cs`:**
```csharp
private readonly string pythonServerUrl = "http://localhost:80";
```

## Отправляемые данные

C# MediaMonitor отправляет на Python сервер:

```json
{
  "artist": "Имя исполнителя",
  "title": "Название трека",
  "position": 45.5,           // текущая позиция в секундах
  "duration": 180.0,          // длительность трека
  "is_playing": true,         // играет или на паузе
  "cover_version": 1,         // версия обложки
  "status": "active"          // статус (active/inactive)
}
```

- Python 3.8+
- aiohttp
- winsdk

## Устранение проблем

### Проблема: C# не может подключиться к серверу

**Решение:**
1. Убедитесь, что Python сервер запущен
2. Проверьте, что порт 80 свободен
3. Проверьте URL в `MediaMonitor.cs`

### Проблема: Обложки не сохраняются

**Решение:**
1. Проверьте права доступа к папке `songinfo/`
2. Убедитесь, что папка существует
3. Проверьте консоль C# на наличие ошибок

### Проблема: Дублирование обновлений

**Решение:**
Отключите встроенный Python мониторинг:
```json
{
  "use_builtin_monitor": false
}
```
