## Детализация этапов

### Этап 1: Обзор литературы и постановка задачи (06.11 - 01.12)

**Задачи:**
- Изучение существующих решений для визуализации мультимедийного контента в стриминговых сервисах (OBS Studio, Streamlabs, XSplit и др.)
- Анализ технологий: системные API медиаплееров (Windows Media Control API, MPRIS для Linux, MediaPlayer для macOS), WebSocket, асинхронное программирование в Python
- Исследование методов интеграции веб-виджетов в стриминговые сервисы
- Анализ алгоритмов извлечения цветовой палитры из изображений
- Изучение кроссплатформенных подходов к разработке десктопных приложений
- Формулировка цели: разработка кроссплатформенной системы управления и визуализации мультимедийного контента для стриминговых сервисов с поддержкой автоматического отображения информации о текущем воспроизводимом контенте
- Определение задач:
  1. Разработать архитектуру кроссплатформенной системы с разделением на desktop-приложение и веб-сервер
  2. Реализовать интеграцию с системными API медиаплееров для получения информации о мультимедийном контенте (Windows Media Control API с возможностью расширения)
  3. Создать систему получения метаданных контента (обложек, информации о треках) из различных источников
  4. Разработать веб-виджеты с настраиваемыми шаблонами визуализации мультимедийного контента
  5. Реализовать алгоритм автоматического извлечения цветовой палитры из обложек для адаптации интерфейса
  6. Оптимизировать производительность системы
  7. Обеспечить интеграцию с популярными стриминговыми сервисами

**Результаты:**
- Отчёт об обзоре литературы (15-20 страниц)
- Анализ 5-7 аналогов систем управления и визуализации мультимедийного контента с таблицей сравнения
- Анализ кроссплатформенных подходов и технологий
- Согласованные формулировки цели и задач ВКР
- Техническое обоснование выбора технологий

## Основные технические характеристики проекта

**Технологический стек:**
- Python 3.12+ (кроссплатформенный язык)
- CustomTkinter (GUI, с возможностью расширения)
- aiohttp (кроссплатформенный веб-сервер)
- Windows Media Control API (получение информации о контенте на Windows, с планами расширения на MPRIS для Linux, MediaPlayer для macOS)
- WebSocket (обновления в реальном времени)
- HTML/CSS/JavaScript (универсальные веб-виджеты)
- PyInstaller (сборка приложения)

**Основные модули:**
1. `main.py` - точка входа приложения
2. `config_manager.py` - управление конфигурацией
3. `ui/app.py` - главное окно приложения
4. `ui/pages/` - страницы интерфейса
5. `now_server/now.py` - веб-сервер
6. `now_server/cover_fetcher.py` - получение обложек
7. `now_server/*.html` - шаблоны визуализации

**Ключевые алгоритмы:**
- Извлечение доминирующих цветов из изображений для адаптации интерфейса
- Оптимизация производительности обработки изображений
- Кэширование результатов для снижения нагрузки на CPU
- Универсальный алгоритм работы с метаданными мультимедийного контента

**Результаты оптимизации:**
- Нагрузка CPU при переключении треков: снижена с 20-35% до 0.8-2%
- Размер canvas для обработки: уменьшен с 200x200 до 80x80 пикселей
- Шаг выборки пикселей: увеличен с 32 до 128 байт
- Добавлено кэширование результатов извлечения цветов
