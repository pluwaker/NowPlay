## 📋 Описание

**NowPlay** — это современное десктопное приложение для Windows, которое отображает информацию о текущем воспроизводимом треке прямо в OBS Studio. Приложение работает через локальный веб-сервер, что позволяет легко интегрировать виджет в любой стрим или запись.

### ✨ Основные возможности

- 🎧 **Автоматическое определение трека** из медиаплееров Windows
- 🖼️ **Автоматическое получение обложек** из Last.fm, iTunes, Yandex Music и VK Music
- 🎨 **Настраиваемые шаблоны** визуализации (4 различных варианта)
- 🌈 **Гибкая настройка цветов** подложки, акцентов и элементов интерфейса
- 🎨 **Автоматические цвета** на основе обложки альбома
- 📊 **Отображение прогресса** воспроизведения с возможностью перемотки
- 🎭 **Анимированный визуализатор** с настраиваемыми параметрами
- 💡 **Подсветка обложки** (ambient light) с автоматической цветовой палитрой
- 📍 **Гибкое позиционирование** виджета на экране
- 🔄 **WebSocket** для обновления данных в реальном времени

## 🚀 Установка

### Системные требования

- **ОС:** Windows 10 или выше
- **Python:** 3.12+ (только для запуска из исходников)
- **OBS Studio:** Любая актуальная версия

### Вариант 1: Использование готового exe-файла

1. Скачайте последнюю версию из раздела [Releases](../../releases)
2. Распакуйте архив
3. Запустите `NowPlay.exe`
4. Готово! 🎉

### Вариант 2: Установка из исходников

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/pluwaker/NowPlay.git
   cd NowPlay
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   
   > **Примечание:** Если файл `requirements.txt` отсутствует, установите зависимости вручную:
   ```bash
   pip install customtkinter aiohttp winsdk
   ```

3. **Запустите приложение:**
   ```bash
   python main.py
   ```

## 📖 Использование

### Быстрый старт

1. **Запустите приложение NowPlay**
   - Откроется главное окно с интерфейсом управления

2. **Нажмите кнопку "🚀 START"**
   - Это запустит локальный веб-сервер
   - В интерфейсе появится ссылка для добавления в OBS

3. **Скопируйте ссылку** (например: `http://localhost:8080/visualisation.html`)

4. **Откройте OBS Studio** и добавьте новый источник:
   - **Тип источника:** Browser Source
   - **URL:** Вставьте скопированную ссылку
   - **Ширина:** 900px (или по желанию)
   - **Высота:** 900px (или по желанию)
   - ✅ Отметьте "Shutdown source when not visible" для экономии ресурсов

5. **Настройте виджет:**
   - Перейдите на вкладку "⚙️ SETTINGS"
   - Выберите шаблон визуализации
   - Настройте цвета и параметры
   - Установите позиционирование виджета на экране

6. **Начните воспроизведение музыки** в любом поддерживаемом медиаплеере

### Поддерживаемые медиаплееры

Приложение работает с любыми медиаплеерами, которые используют Windows Media Control API:
- ✅ Spotify
- ✅ Windows Media Player
- ✅ Groove Music
- ✅ VLC Media Player
- ✅ И многие другие...

### Настройка шаблонов

В приложении доступно **4 различных шаблона** визуализации:

1. **Вертикальный** (`visualisation.html`) - классический вертикальный виджет
2. **Альтернативный** (`visualisation_var2.html`) - компактный вариант с улучшенным дизайном
3. **Минималистичный** (`visualisation_var3.html`) - минимальный дизайн
4. **Горизонтальный** (`visualisation_horizontal.html`) - горизонтальная раскладка с визуализатором

### Настройка цветов

Вы можете настроить:
- 🎨 Цвет подложки (фона)
- 🎨 Акцентный цвет (для текста и элементов)
- 🎨 Цвет волны визуализатора
- 🎨 Цвет прогресс-бара
- 🎨 Цвет текста

Также доступна опция **"Автоматические цвета"**, которая извлекает цветовую палитру из обложки альбома и применяет её к виджету.

### Позиционирование

Виджет можно расположить в любом углу экрана:
- Слева сверху
- Справа сверху
- Слева снизу
- Справа снизу

## 🛠️ Технические детали

### Архитектура

Приложение состоит из трёх основных компонентов:

1. **Desktop Application** (`ui/app.py`)
   - Графический интерфейс на базе CustomTkinter
   - Управление настройками
   - Запуск/остановка сервера

2. **Web Server** (`now_server/now.py`)
   - HTTP сервер на aiohttp
   - WebSocket для обновлений в реальном времени
   - API для получения информации о треке

3. **Cover Fetcher** (`now_server/cover_fetcher.py`)
   - Получение обложек из различных источников
   - Кэширование и оптимизация запросов

### Используемые технологии

- **Python 3.12+** - основной язык программирования
- **CustomTkinter** - современный GUI фреймворк
- **aiohttp** - асинхронный веб-сервер
- **Windows Media Control API** - получение информации о медиа
- **WebSocket** - обновление данных в реальном времени
- **HTML/CSS/JavaScript** - шаблоны визуализации

### Структура проекта

```
NowPlay/
```

## 🐛 Решение проблем

### Виджет не отображается в OBS

1. Убедитесь, что сервер запущен (кнопка "START" активна)
2. Проверьте, что ссылка скопирована правильно
3. Откройте ссылку в браузере для проверки
4. Убедитесь, что в OBS указан правильный URL

### Не определяется текущий трек

1. Проверьте, что медиаплеер запущен и воспроизводит музыку
2. Некоторые медиаплееры требуют специальных настроек для работы с Windows Media Control API
3. Попробуйте перезапустить приложение NowPlay

### Обложка не загружается

1. Проверьте подключение к интернету
2. Попробуйте другой источник обложек в настройках
3. Обложка может быть недоступна на сервисах (особенно для редких треков)

### Высокая нагрузка на CPU

1. Отключите визуализатор в настройках (`wave_enabled: false`)
2. Отключите ambient light, если не нужен
3. Используйте более простой шаблон визуализации
