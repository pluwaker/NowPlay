# Changelog - C# MediaMonitor Integration

## [1.1.1] - 2024-12-07

### 🐛 Исправления

#### Надежное обнаружение источников медиа
- ✅ **КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: Используется существующий SessionManager вместо создания нового**
- ✅ **Исправлена проблема с обнаружением источников при старте**
- ✅ **Исправлена проблема с обнаружением источников при автоматическом переключении трека**
- ✅ Добавлена начальная задержка 500ms перед первой отправкой источников
- ✅ Добавлена задержка 300ms в обработчике SessionsChanged
- ✅ Добавлена повторная проверка источников через 3 секунды после старта
- ✅ Улучшено логирование для диагностики проблем
- ✅ Источники теперь обнаруживаются надежно в любом сценарии

**Проблемы:** 
1. При запуске MediaMonitor выводилось "Обнаружено 0 источников", даже если медиаплеер уже работал
2. При автоматическом переключении трека выводилось "Получено 0 источников от C# MediaMonitor"
3. Источники появлялись только после ручного переключения трека

**Корневая причина:**
`SendAvailableSources()` создавал новый `SessionManager` каждый раз, который не успевал получить актуальный список сессий.

**Решение:** 
- ⭐ **ГЛАВНОЕ:** Используется существующий `sessionManager` вместо создания нового
- Начальная задержка 500ms дает Windows Media API время для инициализации
- Задержка 300ms в обработчике SessionsChanged дает время сессиям обновиться
- Повторная проверка через 3 секунды ловит медиаплееры, запущенные после MediaMonitor
- Улучшенное логирование помогает диагностировать проблемы

**Сценарии работы:**
- ✅ Медиаплеер уже запущен → обнаруживается через 500ms
- ✅ Медиаплеер запускается одновременно → обнаруживается через 3 секунды
- ✅ Медиаплеер запускается позже → обнаруживается при событии SessionsChanged
- ✅ Переключение трека → обнаруживается мгновенно
