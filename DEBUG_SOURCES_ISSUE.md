# Отладка проблемы с обнаружением источников

## Добавлено детальное логирование

Для диагностики проблемы добавлено подробное логирование в MediaMonitor.cs:

### Что логируется:

1. **При событии SessionsChanged:**
   ```
   🔔 Событие SessionsChanged сработало
   ⏳ Ожидание 300ms для обновления сессий...
   📡 Отправка обновленного списка источников...
   ```

2. **При поиске источников:**
   ```
   🔍 Поиск источников... Найдено сессий: X
   ```

3. **Для каждой сессии:**
   ```
   📱 Сессия: AppId
   ✅ Добавлен источник: DisplayName
   ```
   или
   ```
   ⚠️ Ошибка обработки сессии: ErrorMessage
   ```

4. **Итоговая статистика:**
   ```
   📊 Итого найдено источников: X, изменились: true/false, force: true/false
   ```

5. **При отправке на сервер:**
   ```
   📤 Отправка данных на сервер: {"sources":[...]}
   📻 Отправлено источников: X (статус: 200)
   ```

## Как использовать для отладки

### Шаг 1: Пересоберите MediaMonitor

```bash
cd MediaMonitor
dotnet build -c Release
```

### Шаг 4: Анализ проблемы

**Если видите "Найдено сессий: 0":**
- Windows Media API не видит активных медиаплееров
- Возможно, медиаплеер не поддерживает Windows Media Control API
- Попробуйте другой медиаплеер (Spotify, VLC, Windows Media Player)

**Если видите сессии, но "Итого найдено источников: 0":**
- Проблема в обработке сессий
- Проверьте логи "⚠️ Ошибка обработки сессии"
- Возможно, `SourceAppUserModelId` пустой или null

**Если видите источники, но Python сервер получает 0:**
- Проблема в HTTP запросе
- Проверьте статус ответа (должен быть 200)
- Проверьте JSON в логе "📤 Отправка данных на сервер"

**Если видите "📱 Сессия: null":**
- Сессия существует, но не имеет `SourceAppUserModelId`
- Это нормально для некоторых системных сессий
- Они игнорируются

## Типичные проблемы и решения

### Проблема 1: "Найдено сессий: 0" при работающем медиаплеере

**Причина:** Медиаплеер не использует Windows Media Control API

**Решение:**
- Используйте Spotify Desktop (не Web Player)
- Используйте VLC Media Player
- Используйте Windows Media Player
- Проверьте, что музыка действительно воспроизводится

### Проблема 2: Сессии есть, но источники не добавляются

**Причина:** `SourceAppUserModelId` пустой или null

**Решение:**
- Это баг медиаплеера
- Попробуйте перезапустить медиаплеер
- Попробуйте другой медиаплеер

### Проблема 3: Источники отправляются, но Python получает 0

**Причина:** Проблема с HTTP запросом или сериализацией

**Решение:**
- Проверьте статус ответа в логах
- Проверьте JSON в логе "📤 Отправка данных"
- Проверьте, что Python сервер запущен на правильном порту

### Проблема 4: При автоматическом переключении "Найдено сессий: 0"

**Причина:** Windows Media API временно "теряет" сессии

**Решение:**
- Увеличьте задержку в `OnSessionsChanged` с 300ms до 500ms
- Это редкая проблема, зависит от медиаплеера
