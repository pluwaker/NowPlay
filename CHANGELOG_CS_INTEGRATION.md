# Changelog - C# MediaMonitor Integration

## [1.0.0] - 2024-11-12

### 🎉 Добавлено

#### C# MediaMonitor Application
- ✅ Создан полноценный C# проект для мониторинга Windows Media
- ✅ Нативная интеграция с Windows Media Control API
- ✅ Автоматическое отслеживание смены треков
- ✅ Загрузка и сохранение обложек альбомов
- ✅ Отправка данных на Python сервер через HTTP API
- ✅ Асинхронная обработка треков для лучшей производительности

**Файлы:**
- `MediaMonitor/MediaMonitor.cs` - основная логика мониторинга
- `MediaMonitor/CoverFetcher.cs` - загрузка обложек
- `MediaMonitor/CurrentMediaState.cs` - модель данных
- `MediaMonitor/Program.cs` - точка входа
- `MediaMonitor/MediaMonitor.csproj` - конфигурация проекта

#### Python Server Integration
- ✅ Новый endpoint `/update_from_cs` для приема данных от C#
- ✅ Поддержка отключения встроенного Python мониторинга
- ✅ Троттлинг обновлений для оптимизации производительности
- ✅ Автоматическая очистка мертвых WebSocket соединений

**Изменения в `now_server/now.py`:**
- Добавлен `update_from_cs()` endpoint
- Добавлена опция `use_builtin_monitor` в конфигурации
- Улучшена обработка WebSocket соединений

#### Автоматизация

- ✅ `test_integration.py` - тестовый скрипт для проверки интеграции

### 🚀 Улучшения

#### Производительность
- ⚡ Более быстрая реакция на смену треков (нативный C# vs Python)
- ⚡ Меньше нагрузка на CPU при использовании C# мониторинга
- ⚡ Оптимизированная обработка обложек
- ⚡ Троттлинг обновлений (100ms минимум между отправками)

#### Надежность
- 🛡️ Автоматическая отмена предыдущих задач при смене трека
- 🛡️ Обработка ошибок HTTP соединения
- 🛡️ Очистка мертвых WebSocket соединений
- 🛡️ Graceful degradation при недоступности сервера

- 🔧 Поддержка гибридного режима (оба мониторинга)

### 📝 Примечания

#### Режимы работы

**Рекомендуемый режим:** C# MediaMonitor + Python Server
```json
{
  "use_builtin_monitor": false
}
```

**Альтернативный режим:** Только Python мониторинг
```json
{
  "use_builtin_monitor": true
}
```

**Режим отладки:** Оба мониторинга (не рекомендуется для продакшена)
```json
{
  "use_builtin_monitor": true
}
+ запущен C# MediaMonitor
```
