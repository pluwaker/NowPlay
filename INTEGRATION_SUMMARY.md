## 🔄 Режимы работы

### Режим 1: Только Python (по умолчанию)
```json
{
  "use_builtin_monitor": true
}
```
- Не требует .NET
- Все в одном процессе
- Простая настройка

### Режим 2: C# + Python (рекомендуется)
```json
{
  "use_builtin_monitor": false
}
```
- Быстрая реакция
- Меньше нагрузка
- Лучшая производительность

## 🎨 Архитектура

```
Windows Media → C# MediaMonitor → HTTP POST → Python Server → WebSocket → Клиенты
```

## 🐛 Устранение проблем

### Частые проблемы

| Проблема | Решение |
|----------|---------|
| Порт 80 занят | Измените порт в `now.py` и `MediaMonitor.cs` |
| C# не подключается | Убедитесь, что Python сервер запущен |
| Обложки не загружаются | Проверьте права доступа к папке `songinfo/` |
| Высокая нагрузка CPU | Отключите встроенный Python мониторинг |

Подробнее в [FAQ.md](FAQ.md)
