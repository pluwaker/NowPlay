# Оптимизация HTML файлов

## 🎯 Минификация HTML файлов

Для уменьшения размера HTML файлов используется скрипт `minify_html.py`.

### Что делает минификация:

1. **Удаляет HTML комментарии** (кроме важных `<!--!`)
2. **Удаляет лишние пробелы и переносы строк**
3. **Минифицирует CSS** внутри `<style>`:
   - Удаляет комментарии `/* ... */`
   - Убирает лишние пробелы
   - Оптимизирует форматирование
4. **Минифицирует JavaScript** внутри `<script>`:
   - Удаляет комментарии `//` и `/* */`
   - Убирает лишние пробелы
   - Оптимизирует форматирование

### Запуск:

```bash
python minify_html.py
```

### Ожидаемый результат:

- **visualisation.html**: ~60-80 KB -> ~40-50 KB (экономия ~30%)
- **visualisation_var2.html**: ~60-80 KB -> ~40-50 KB (экономия ~30%)
- **visualisation_var3.html**: ~60-80 KB -> ~40-50 KB (экономия ~30%)
- **visualisation_horizontal.html**: ~60-80 KB -> ~40-50 KB (экономия ~30%)
- **index.html**: ~5-10 KB -> ~3-5 KB (экономия ~40%)

**Общая экономия**: ~50-100 KB в зависимости от файлов

### ⚠️ Важно:

- Скрипт **перезаписывает** исходные HTML файлы
- Рекомендуется сделать **backup** перед минификацией
- После минификации код труднее читать, но функциональность сохраняется

### Откат изменений:

Если нужно вернуть читаемый формат, используйте git:

```bash
git checkout now_server/*.html
```

Или восстановите из backup.

## 📝 Альтернативные варианты

### 1. Использовать внешние инструменты:

- **html-minifier-terser** (Node.js): `npx html-minifier-terser --file visualisation.html --output visualisation.min.html`
- **Online минификаторы**: https://www.minifier.org/

### 2. Добавить минификацию в build процесс:

Можно добавить минификацию в `build.py` или `build.spec` чтобы автоматически минифицировать HTML при сборке.
