# 🔧 Исправление проблемы с портом - ГОТОВО!

## ✅ Что было исправлено

MediaMonitor теперь использует **правильный порт 58080** вместо 8080.

## 🚀 Как запустить (ПРОСТО!)

### Способ 1: Через интерфейс (рекомендуется)

1. Запустите приложение:
   ```bash
   python main.py
   ```

2. Нажмите кнопку **"🚀 START"**

3. Всё! Приложение автоматически:
   - Запустит сервер на порту 58080
   - Запустит MediaMonitor
   - Подключит MediaMonitor к серверу

4. Откройте виджет по ссылке из интерфейса

### Способ 2: Вручную (для продвинутых)

1. **Запустите сервер:**
   ```bash
   python -c "from now_server.now import run_server; run_server(port=58080)"
   ```

2. **Запустите MediaMonitor:**
   ```bash
   cd MediaMonitor
   .\bin\Release\net6.0-windows10.0.19041.0\MediaMonitor.exe
   ```

3. **Откройте виджет:**
   ```
   http://localhost:58080/visualisation_var3_horizontal.html
   ```

## 🔍 Если что-то не работает

### Проблема: "Порт занят"

**Решение:** Приложение автоматически найдет свободный порт (58080-59000)

### Проблема: MediaMonitor не отправляет данные

**Решение:**
1. Убедитесь, что сервер запущен ПЕРВЫМ
2. Перезапустите MediaMonitor
3. Проверьте порт в консоли

### Проблема: Виджет не показывает трек

**Решение:**
1. Включите музыку в любом плеере (Spotify, iTunes, YouTube и т.д.)
2. Обновите страницу виджета (F5)
3. Проверьте консоль браузера (F12)
