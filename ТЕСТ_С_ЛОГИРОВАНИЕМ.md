# 🔍 Тест с расширенным логированием

## Что изменилось

Добавлено **подробное логирование** в HealthMonitor, чтобы увидеть, что именно происходит.

## Как тестировать

### Шаг 1: Остановите старый MediaMonitor

Если MediaMonitor уже запущен - закройте его (Ctrl+C).

### Шаг 2: Запустите новую версию

```bash
cd MediaMonitor\bin\Release\net6.0-windows10.0.19041.0
.\MediaMonitor.exe
```

**Не нужен флаг --diagnostic!** Логирование уже встроено.

### Шаг 3: Проверьте вывод при старте

Вы ДОЛЖНЫ увидеть:

```
✅ MediaMonitor запущен!
🔗 Подключение к серверу: http://localhost:58080
...
🔄 Запуск HealthMonitor...
🔄 HealthMonitor.Start() вызван
📅 Устанавливаем lastUpdateReceived = 19:30:45.123
⏰ Создаем Timer с интервалом 5s
✅ HealthMonitor started (timeout: 30s, heartbeat: 5s)
✅ HealthMonitor запущен успешно
🎵 Мониторинг медиа активен
```

**КРИТИЧНО:** Если вы НЕ видите эти строки - сообщите мне!

### Шаг 4: Подождите 5 секунд

Через 5 секунд вы ДОЛЖНЫ увидеть:

```
[HEALTH] Heartbeat check: Last update 5.0 seconds ago (healthy)
```

Затем каждые 5 секунд:

```
[HEALTH] Heartbeat check: Last update 10.0 seconds ago (healthy)
[HEALTH] Heartbeat check: Last update 15.0 seconds ago (healthy)
[HEALTH] Heartbeat check: Last update 20.0 seconds ago (healthy)
[HEALTH] Heartbeat check: Last update 25.0 seconds ago (healthy)
[HEALTH] Heartbeat check: Last update 30.0 seconds ago (healthy)
```

### Шаг 5: Через 30 секунд

Вы ДОЛЖНЫ увидеть:

```
[HEALTH] Heartbeat check: Last update 30.0 seconds ago (healthy)
❤️ Health Status: UNHEALTHY - No updates received for 30.0 seconds
⚠️ Triggering recovery procedure...
🚨 Вызываем OnRecoveryNeeded()
🔄 Запуск процедуры восстановления...
[RECOVERY] Initiating recovery procedure (attempt 1/3)
```

## Что проверить

### ✅ Если всё работает:

1. Видите строку `✅ HealthMonitor started`
2. Каждые 5 секунд видите `[HEALTH] Heartbeat check`
3. Через 30 секунд видите восстановление

**Результат:** Система работает правильно!

### ❌ Если НЕ видите `✅ HealthMonitor started`:

Вы увидите:

```
🔄 Запуск HealthMonitor...
❌ ОШИБКА запуска HealthMonitor: [сообщение об ошибке]
   Stack trace: [трассировка стека]
```

**Результат:** Ошибка в коде HealthMonitor. Отправьте мне сообщение об ошибке.

### ❌ Если НЕ видите `[HEALTH] Heartbeat check`:

HealthMonitor запустился, но таймер не работает.

**Результат:** Проблема с Timer. Отправьте мне полный вывод консоли.

### ❌ Если видите heartbeat, но восстановление не срабатывает:

Вы видите:

```
[HEALTH] Heartbeat check: Last update 30.0 seconds ago (healthy)
[HEALTH] Heartbeat check: Last update 35.0 seconds ago (healthy)
[HEALTH] Heartbeat check: Last update 40.0 seconds ago (healthy)
```

Но НЕ видите:

```
❤️ Health Status: UNHEALTHY
```

**Результат:** Проблема с логикой обнаружения таймаута. Отправьте мне вывод.

## Проблема с обложкой

Обложка загружается только после перезагрузки страницы - это означает, что **WebSocket не отправляет обновление**.

### Проверка WebSocket

1. Откройте виджет в браузере
2. Нажмите F12 (консоль разработчика)
3. Перейдите на вкладку Console
4. Смените трек в медиа-плеере
5. Проверьте, приходят ли сообщения в консоль

**Должно быть:**

```javascript
{type: "update", data: {artist: "...", title: "...", cover_url: "/cover?v=2", ...}}
```

**Если сообщений НЕТ:**
- WebSocket не подключен
- Или Python сервер не отправляет обновления

### Проверка Python сервера

В консоли Python сервера должно быть:

```
📥 Обновление получено от C#
🎵 Artist - Title
✅ Обложка загружена
```

**Если этого НЕТ:**
- MediaMonitor не отправляет данные на сервер
- Проверьте, что порт правильный (58080)
