# 📦 Руководство по созданию релиза на GitHub

## 🚀 Быстрый способ (ZIP архив)

### 1. Соберите приложение

```bash
pyinstaller build.spec
```

### 2. Создайте ZIP архив

```bash
python package_release.py
```

Это создаст файл `release/NowPlay-v1.0.0-Windows.zip`

### 3. Загрузите на GitHub

1. Перейдите на https://github.com/ваш-username/NowPlay/releases/new
2. Создайте новый тег (например, `v1.0.0`)
3. Добавьте название: `NowPlay v1.0.0`
4. Загрузите файл из папки `release/`
5. Добавьте описание:
   ```
   ## 📥 Установка
   
   1. Скачайте `NowPlay-v1.0.0-Windows.zip`
   2. Распакуйте архив
   3. Откройте папку `NowPlay`
   4. Запустите `NowPlay.exe`
   
   ## ✨ Что нового
   
   - Оптимизирована производительность (CPU: 0.8-2% вместо 20-35%)
   - Использован режим --onedir для быстрой работы
   - Улучшено извлечение цветов из обложек
   ```
6. Нажмите "Publish release"

## 📋 Полный процесс

### Шаг 1: Обновите версию (опционально)

В `config.json`:
```json
{
  "version": "1.0.0",
  ...
}
```

### Шаг 2: Соберите приложение

```bash
# Очистите старые сборки
rmdir /s /q build dist

# Соберите
pyinstaller build.spec
```

### Шаг 3: Создайте релиз

```bash
python package_release.py
```

### Шаг 4: Проверьте результат

Убедитесь, что файл создан:
```
release/
└── NowPlay-v1.0.0-Windows.zip
```

### Шаг 5: Создайте тег и релиз на GitHub

```bash
# Создайте тег
git tag v1.0.0
git push origin v1.0.0

# Или через GitHub веб-интерфейс:
# 1. Перейдите в Releases
# 2. Нажмите "Draft a new release"
# 3. Выберите или создайте тег
# 4. Загрузите ZIP файл
```

## 🎯 Автоматический способ (GitHub Actions)

Если настроен `.github/workflows/build-release.yml`:

1. Создайте тег:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```

2. GitHub Actions автоматически:
   - Соберет приложение
   - Создаст ZIP архив
   - Создаст релиз с файлом

## 📦 Альтернатива: Создание установщика (Inno Setup)

### 1. Установите Inno Setup

Скачайте с https://jrsoftware.org/isdl.php

### 2. Скомпилируйте установщик

1. Откройте `setup_inno.iss` в Inno Setup Compiler
2. Нажмите "Build" → "Compile"
3. Установщик будет в папке `release/`

### 3. Загрузите установщик на GitHub

Вместо ZIP архива можно загрузить `.exe` установщик.

## ❓ FAQ

### Почему ZIP, а не один exe файл?

Режим `--onedir` (папка с файлами) работает в **10-50 раз быстрее** чем `--onefile` (один файл), так как не нужно распаковывать файлы при каждом запуске.

### Можно ли создать установщик?

Да, используйте Inno Setup (файл `setup_inno.iss`). Но ZIP архив проще и быстрее для пользователей.

### Как автоматизировать создание релиза?

Используйте GitHub Actions (файл `.github/workflows/build-release.yml`). Просто создайте тег и релиз создастся автоматически.
