# Быстрое исправление: Синхронизация портов

## Что было исправлено

Теперь MediaMonitor автоматически подключается к правильному порту Python сервера, даже если порт 8080 занят.

## Что нужно сделать

### Для пользователей

**Ничего!** Изменения работают автоматически. Просто запустите приложение как обычно.

### Для разработчиков

После внесения изменений необходимо **пересобрать MediaMonitor.exe**:

```bash
# Перейдите в папку MediaMonitor
cd MediaMonitor

# Соберите проект
dotnet build -c Release
```

Или используйте Visual Studio для сборки проекта.

## Проверка работы

1. Запустите приложение через `main.py` или `run_app.pyw`
2. В консоли вы увидите:
   ```
   ✅ Сервер запущен на http://localhost:58080
   ✅ MediaMonitor started (PID: YYYY, Port: 58080)
   ```
3. Порты должны совпадать!

**Примечание:** Порт по умолчанию изменен с 8080 на 58080 для избежания конфликтов.

## Если что-то не работает

1. Убедитесь, что MediaMonitor.exe пересобран после изменений
2. Проверьте консоль на наличие ошибок
3. Убедитесь, что порт не заблокирован файрволом
