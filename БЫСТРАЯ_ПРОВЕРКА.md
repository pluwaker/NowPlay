## Проверка #2: Обложка не отображается

### Возможные причины:

1. **Обложка не отправлена на сервер**
   - MediaMonitor скачал обложку локально
   - Но не отправил на Python сервер

2. **Виджет не обновился**
   - Обложка есть, но виджет не перезагрузил изображение
   - Нужно обновить `cover_version`

3. **Путь к обложке неправильный**
   - Виджет ищет обложку не там

### Быстрая проверка:

1. **Проверьте, что обложка существует:**
   ```bash
   dir songinfo\cover.png
   ```
   
   Должен показать файл `cover.png`

2. **Откройте обложку в браузере:**
   ```
   http://localhost:58080/cover
   ```
   
   Должна открыться обложка альбома

3. **Проверьте консоль браузера (F12):**
   - Откройте виджет
   - Нажмите F12
   - Перейдите на вкладку Console
   - Ищите ошибки загрузки изображения

**Если событие НЕ сработало:**

## Решение проблемы с обложкой

### Вариант 1: Обновите страницу виджета

Просто нажмите **F5** в браузере с виджетом.

### Вариант 2: Проверьте WebSocket соединение

1. Откройте консоль браузера (F12)
2. Перейдите на вкладку Network
3. Фильтр: WS (WebSocket)
4. Должно быть активное соединение к `ws://localhost:58080/ws`

### Вариант 3: Проверьте, что сервер отправляет обложку

В консоли Python сервера должно быть:
```
✅ Обложка загружена для: Artist - Title
```

И при отправке обновления:
```
📥 Обновление #1 получено
🎵 Artist - Title
```

## Быстрое решение

### Если события не срабатывают:

1. **Подождите 30 секунд** - восстановление сработает автоматически
2. Если не помогло - **перезапустите MediaMonitor**
3. Если всё равно не помогает - **перезапустите медиа-плеер**

### Если обложка не отображается:

1. **Обновите страницу виджета (F5)**
