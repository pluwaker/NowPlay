## Добавленные функции в common.js

### 1. hasGoodContrast() ✅ НОВАЯ

**Описание:** Проверяет контраст между текстом и фоном по стандарту WCAG AA.

**Сигнатура:**
```javascript
function hasGoodContrast(textColor, bgColor, minRatio = 4.5)
```

**Параметры:**
- `textColor` - Цвет текста (строка в формате rgba)
- `bgColor` - Цвет фона (строка в формате rgba)
- `minRatio` - Минимальное соотношение контраста (по умолчанию 4.5)

**Возвращает:** `boolean` - true если контраст достаточный

**Использование:**
```javascript
if (!hasGoodContrast(textColor, bgColor)) {
    // Улучшаем контраст
    textColor = ensureLightColor(textColor, 200);
}
```

### 2. applyAutoColors() ✅ УЛУЧШЕНА

**Описание:** Применяет автоматические цвета на основе обложки с проверкой контраста.

**Изменения:**
- ✅ Добавлена проверка контраста с использованием `hasGoodContrast()`
- ✅ Улучшена логика выбора цвета текста для обеспечения читаемости
- ✅ Добавлена адаптивная логика для цвета фона прогресс-бара
- ✅ Добавлены console.log для отладки

**Сигнатура:**
```javascript
function applyAutoColors(colors, edgeColors, config)
```

**Параметры:**
- `colors` - Объект с доминантными цветами `{first, second}`
- `edgeColors` - Объект с цветами краев `{top, right, bottom, left}`
- `config` - Объект конфигурации с флагом `auto_colors_enabled`

**Логика работы:**
1. Проверяет, включены ли автоматические цвета
2. Применяет ambient light на основе цветов краев
3. Выбирает цвет для подложки (первый или второй доминантный)
4. Корректирует яркость подложки
5. Снижает насыщенность для мягкости
6. Выбирает цвет для текста (второй доминантный)
7. **Проверяет контраст** между текстом и фоном
8. Осветляет текст если контраст недостаточный
9. Использует белый цвет если контраст все еще плохой
10. Применяет цвета к CSS переменным
11. Вычисляет цвет фона прогресс-бара на основе яркости текста

## Тестирование

### Проверка контраста

Функция `hasGoodContrast()` использует формулу относительной яркости из стандарта WCAG:

```
L = 0.2126 * R + 0.7152 * G + 0.0722 * B
```

Где R, G, B нормализованы по формуле:
```
если val <= 0.03928:
    val / 12.92
иначе:
    ((val + 0.055) / 1.055) ^ 2.4
```

Соотношение контраста вычисляется как:
```
ratio = (max(L1, L2) + 0.05) / (min(L1, L2) + 0.05)
```

Минимальное соотношение для WCAG AA: **4.5:1**

### Ручное тестирование

Для проверки работы унифицированных функций:

1. Откройте каждый HTML шаблон в браузере
2. Проверьте консоль на наличие сообщений:
   - "Первый цвет слишком темный для подложки, используем второй цвет"
   - "Цвет подложки слишком светлый (X), затемняем на Y"
   - "Контраст недостаточный, осветляем текст"
   - "Контраст все еще недостаточный, используем белый цвет"
3. Убедитесь, что текст хорошо читается на фоне
4. Проверьте, что ambient light работает корректно
5. Переключите несколько треков с разными обложками
