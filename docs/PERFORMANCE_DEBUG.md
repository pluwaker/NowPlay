# 🔍 Отладка производительности NowPlay

## Проблема: Высокая нагрузка на CPU при переключении треков

### Инструменты для отладки

#### 1. **Chrome DevTools Performance Profiler** (Рекомендуется)

Это самый мощный инструмент для отладки производительности JavaScript в браузере.

**Как использовать:**

1. Откройте OBS Studio и добавьте ваш виджет как Browser Source
2. В OBS: Правый клик на источник → "Interact" → откроется браузер
3. В браузере: `F12` или `Ctrl+Shift+I` → вкладка **Performance**
4. Нажмите **Record** (кнопка записи)
5. Переключите трек в медиаплеере
6. Подождите 5-10 секунд
7. Нажмите **Stop**
8. Анализируйте результаты:
   - **Main Thread** - показывает какие функции выполняются
   - **FPS** - частота кадров (должна быть 60)
   - **CPU Usage** - использование CPU
   - Наведите на функции - увидите время выполнения

**Что искать:**
- Функции с длительным выполнением (красные полосы)
- `getDominantColors` - должна быть быстрой после оптимизации
- `drawImage`, `getImageData` - операции с canvas
- Множественные вызовы `filter()`, `sort()`, `map()`

#### 2. **Performance API в JavaScript** (Встроено в код)

В код уже добавлены замеры производительности. Для их активации:

1. Откройте консоль браузера (`F12` → Console)
2. Введите: `window.DEBUG_PERFORMANCE = true`
3. Переключите трек
4. В консоли увидите:
   ```
   [PERF] getDominantColors: 45.23ms
   [PERF STATS] Извлечений: 10, Кеш попаданий: 5, Среднее время: 42.15ms
   ```

**Статистика доступна в глобальной переменной:**
```javascript
// В консоли браузера:
console.log(window.performanceStats);
// Покажет:
// {
//   colorExtractions: 10,
//   totalTime: 421.5,
//   maxTime: 89.2,
//   minTime: 12.3,
//   cacheHits: 5
// }
```

#### 3. **Performance Monitor в Chrome DevTools**

1. `F12` → вкладка **Performance Monitor**
2. Включите мониторинг:
   - CPU usage
   - JS heap size
   - Event listeners
3. Переключите трек и наблюдайте за графиками

#### 4. **Memory Profiler**

Если подозреваете утечки памяти:

1. `F12` → вкладка **Memory**
2. Выберите "Heap snapshot"
3. Нажмите "Take snapshot"
4. Переключите несколько треков
5. Снова "Take snapshot"
6. Сравните - не должно быть утечек

### Что НЕ использовать

❌ **psutil** - это Python библиотека для системного мониторинга, не подходит для JavaScript в браузере

✅ **Chrome DevTools** - правильный инструмент для отладки браузерного JavaScript

### Типичные проблемы и решения

#### 1. Медленное извлечение цветов
**Признаки:** `getDominantColors` занимает > 100ms
**Решение:** 
- Уменьшить размер canvas (уже сделано: 80x80)
- Увеличить шаг выборки (уже сделано: 128)
- Проверить кеш (должно быть много cacheHits)

#### 2. Блокировка главного потока
**Признаки:** FPS падает ниже 60, UI "зависает"
**Решение:**
- Использовать `requestIdleCallback` (уже добавлено)
- Вынести вычисления в Web Worker (если нужно)

#### 3. Множественные пересчеты
**Признаки:** Одна функция вызывается много раз
**Решение:**
- Дебаунсинг (уже добавлен: 50ms)
- Кеширование (уже добавлено)

#### 4. Утечки памяти
**Признаки:** Память растет при переключении треков
**Решение:**
- Очистка кеша (максимум 50 записей)
- Удаление обработчиков событий

### Быстрая проверка производительности

1. Откройте консоль браузера
2. Введите:
```javascript
// Включить отладку
window.DEBUG_PERFORMANCE = true;

// Проверить статистику
console.log('Статистика:', window.performanceStats);

// Принудительно очистить кеш
window.colorCache.clear();
```

3. Переключите несколько треков
4. Проверьте статистику:
```javascript
console.log('После переключений:', window.performanceStats);
```

### Ожидаемые значения (после оптимизации)

- **getDominantColors (без кеша):** < 50ms
- **getDominantColors (с кешем):** < 1ms
- **CPU при переключении:** 2-5% (было 20%)
- **FPS:** стабильно 60

### Пример отладки

```javascript
// В консоли браузера:

// 1. Включить детальное логирование
window.DEBUG_PERFORMANCE = true;

// 2. Запустить профилирование
console.profile('Track Switch');
// ... переключить трек ...
console.profileEnd('Track Switch');

// 3. Проверить производительность
performance.getEntriesByType('measure').forEach(entry => {
    console.log(`${entry.name}: ${entry.duration}ms`);
});
```

### Рекомендации

1. **Всегда используйте Chrome DevTools** для профилирования браузерного кода
2. **Проверяйте консоль** на наличие ошибок и предупреждений
3. **Мониторьте FPS** - должно быть стабильно 60
4. **Используйте встроенные замеры** (`window.DEBUG_PERFORMANCE = true`)
5. **Проверяйте кеш** - должно быть много cacheHits при повторных треках
